# نسخة جوجل بلاي («مغامرات العيلة») – دليل المالك والمطوّر

**English in short:** one GENERIC edition for any family. `build.js` turns the game into a standalone web app whose strings use ROLE TOKENS (`{m} {a} {t} {n} {gm} {aunt1} {cz1} …`);
`engine/family.js` + `engine/family_ui.js` (a first-launch WIZARD) resolve them at RUN time from `Moody.save.data.family` (device only, no network). The narration is NEUTRAL
(tokens are spoken as neutral words) so the pre-generated clips work for every family. The original `moody/` is never modified by the build.

## 1) البناء والتشغيل
```bash
cd moody
node tools/play/build.js /path/to/play_out --force            # يخرج لعبة كاملة مستقلة (+ /path/to/play_out.meta/build-report.json)
node tools/play/leakcheck.js /path/to/play_out                # لازم: no leaks found
python3 -m http.server 8901 --directory /path/to    # ثم افتح http://localhost:8901/play_out/index.html
```
أول تشغيل يفتح **المعالج** (أهلًا بيكم): عدد الأطفال (١–٤)، الأسماء/السن/الشكل، الجدة (+اللقب: جدتي/تيتة/ننا/ستو/ماما) والجد (جدو/سيدو/جدي)، العمّتين والعم، ولاد العم، بابا مسافر؟ (+المدينة)، اسم المدرسة.
زر «جرّب بالأسماء الافتراضية» يتخطّى كل شيء (أسماء: يوسف، آدم، مريم، ليلى …). التعديل بعدها من **ركن الأهل ← عيلتنا: الأسماء والشكل**. ملاحظة خصوصية داخل المعالج: كل شيء على الجهاز فقط.

## 2) الهندسة
| ملف | دوره |
|---|---|
| `engine/family.js` | نموذج البيانات (`save.data.family`)، الأدوار، التوكنات (`Moody.fmt`)، الشكل (`lookProps` → صفوف `DEFS`)، توفّر العوالم، إخفاء الأدوار الثانوية، إعدادات اختبار (`preset`) |
| `engine/family_ui.js` | المعالج + محرّر العيلة (نفس الخطوات) مع معاينة بالشخصية الحقيقية، تعليمات صوتية بلا أسماء |
| `engine/voice.js` (+`tools/voice_hash.py`) | **الصوت المحايد**: جدول ثانٍ للتطبيع، `Moody.voice.neutral=true` في نسخة بلاي فقط (خامل في اللعبة الأصلية) |
| `tools/play/build.js` | القاموس → توكنات، إعادة تسمية المعرّفات، تعميم المحتوى، تفعيل المحرّكين، فحوصات |
| `tools/play/{collect.js,voice.py,check_neutral.js}` | جمع جمل الصوت، توليد الفرق فقط (مع حارس الترخيص)، مطابقة الـ hash بين JS وPython |
| `tools/play/{e2e,wizard_shots,names_check,looktest,icons,leakcheck}.js` | اختبارات (انظر 6) |

### التوكنات
`{m}`=`{k1}` الولد الأكبر (id `moody`) · `{a}`=`{k2}` الولد الأصغر (`aboody`) · `{t}`=`{k3}` البنت الكبيرة (`toota`) · `{n}`=`{k4}` البنت الصغيرة (`nemo`) · `{me}` اسم الطفل نفسه (أو «يا بطل»)
· `{gm}` لقب+اسم الجدة · `{gmt}` اللقب فقط · `{gmn}` الاسم فقط · `{gf}` `{gft}` الجد · `{aunt1}` `{aunt2}` «عمتو+اسم» · `{uncle1}` «عمو+اسم» · `{aunt1n}` `{aunt2n}` `{uncle1n}` الاسم بدون لقب (كلام بابا وتيتة)
· `{cz1}`..`{cz5}` ولاد العم والعمّات (`cz1` = **صاحب كل العوالم** `{fr}`) · `{school}` · `{dcity}` `{dcountry}` مدينة/بلد بابا. أي نص في اللعبة (حوار، عنوان، سؤال، يوميات، ملصقات، رسم على الكانفاس) يمر على `Moody.fmt`.

### الصوت المحايد (جدول واحد في JS وPython)
| توكن | غير النداء | النداء (`يا {x}`) |
|---|---|---|
| `{m}` `{a}` | الكبير / الصغير | يا بطل |
| `{t}` `{n}` | الكبيرة / الصغيرة | يا بطلة |
| `{gm}{gmt}{gmn}` | **لقب الجدة الذي اختاره الأهل** (٥ نسخ من المقطع) | يا + اللقب |
| `{gf}{gft}` | لقب الجد (٣ نسخ) | يا + اللقب |
| `{aunt1}{aunt2}` (+`n`) | عمتو | يا عمتو |
| `{uncle1}` (+`n`) | عمو | يا عمو |
| `{cz1}` `{cz2}` `{cz3}` `{cz4}` `{cz5}` | ابن عمك / بنت عمك / ابن عمك الصغير / الكبير / الأكبر | يا صاحبي / يا حبيبتي / يا حبيبي … |
| `{fr}` | صاحبك | يا صاحبي |
| `{school}` | المدرسة | – |
| `{dcity}` `{dcountry}` | مدينة بابا / بلد بابا | – |
الجمل بلا توكن تحتفظ بنصها فيبقى نفس الـ hash (مقطع قديم قابل لإعادة الاستعمال). **الأسماء الحقيقية تظهر في النص فقط ولا تُنطق أبدًا** (e2e يفحص ذلك).

## 3) توليد الصوت (الفروق فقط)
```bash
node tools/play/collect.js /path/to/play_out                    # يلعب كل المهام ويجمع الجمل (محايدة + الخام)
python3 tools/play/voice.py plan  /path/to/play_out            # كم جملة جديدة + تقدير التكلفة
python3 tools/play/voice.py gen   /path/to/play_out --provider edge --preview --reuse-base    # تجربة المالك المجانية فقط!
python3 tools/play/voice.py gen   /path/to/play_out --provider azure --yes                    # للإصدار التجاري (ترخيص Azure)
python3 tools/play/voice.py check /path/to/play_out            # JS == Python لكل جملة ولكل لقب
node   tools/play/check_neutral.js /path/to/play_out.meta/voice_strings.json
```
**تنبيه ترخيص:** مقاطع `assets/voice` الحالية وخدمة Edge **غير مرخَّصة تجاريًا**؛ حارس `tools/family/voice.py` يرفض `edge` بلا `--preview`، وبناء بلاي يخرج بمانيفست **فارغ**. لإصدار المتجر: Azure (أو تسجيلات بشرية: `script` + `import`) لكل الجمل (`--all`). `--gm-titles`/`--gf-titles` تحدد الألقاب التي تُولَّد (لقب بلا مقطع = صامت).

## 4) ما الذي يمكن ضبطه
عدد الأطفال ١–٤ (اختيار أي خانات من الأربع)، اسم/سن/شكل كل طفل (بشرة ٦، شعر، لون شعر، حجاب+لون للبنات، نضارة، قبعة+لون، لون الملابس)، الجدة/الجد (لقب+اسم+شكل)، عمّتان وعم، ٥ ولاد عم/عمّات (اسم+لون+نضارة…)، بابا مسافر + مدينة من قائمة جبلية قصيرة (مدينة بابا/الطائف/الباحة/صلالة/عجلون)، اسم المدرسة.

## 5) القيود (بصراحة)
1. **جنس كل خانة ثابت** (ولد أكبر/ولد أصغر/بنت كبيرة/بنت صغيرة) لأن العربية مؤنثة/مذكرة داخل النص. لا قلب في وقت التشغيل. عائلة بثلاثة أولاد: خانتا الأولاد + الثالث «صديق». عائلة بنات فقط: الأخوان في عوالم الثنائي (البيت/المدرسة/الشارع/السوق/الحديقة/البحر) هما شخصيتان افتراضيتان (يوسف وآدم) والبنات يلعبن في كل العوالم التي تفتح التحكم للأربعة (الجدة، التجمّع، السفر، العادات، السباق) — **قيد كبير** يحتاج نسخة نص ثانية لو أردت أن تلعب البنتان كثنائي أساسي.
2. الخانات غير المختارة تبقى **أصحابًا بأسماء افتراضية**؛ والأقارب غير المفعّلين **يبقون أشخاصًا افتراضيين** (لا تُحذف لأن أسئلة العدّ والمشاهد تعتمد عليهم). لا يُحذف إلا: عالم بيت الجدة + التجمّع بدون جدة؛ عالم السفر + مكالمات بابا + مراحل السباق المرتبطة بدون سفر؛ والعم/ابنه/الجد/العمة الثانية كأدوار ثانوية في عوالم محددة (`F.MUTE`).
3. علاقات القرابة ثابتة: الجدة أم بابا، العمّتان أختا بابا، العم أخو بابا، `cz1/cz4/cz5` أبناء العمة الأولى، `cz2` بنت العمة الثانية، `cz3` ابن العم. شكل وسن ولاد العم ثابتان (الاسم واللون فقط).
4. عالم السفر: مناظره جبال وضباب وتلفريك ومباني حجر؛ لذلك القائمة مدن جبلية فقط وأسئلة الحقائق استُبدلت بأسئلة محايدة. عالم الجدة مبني على «أسانسير العمارة نفسها» (الدور ٦ إلى ٣).
5. اللهجة مصرية، ومعلومات عامة مصرية (عاصمة مصر، النيل…) باقية. عالم «عاداتي كل يوم» إسلامي — تأكد أنه مناسب لجمهورك.
6. الصوت المحايد يجعل الجملة تُنطق «الصغير» بينما النص «آدم» (حد أدنى من عدم التطابق)؛ جمل الأقارب أثقل (ابن عمك الكبير…).
7. حد الأسماء ١٢ حرفًا. لا صور حقيقية إطلاقًا؛ الأفاتار مرسوم بالكود.

## 6) الاختبارات
`e2e.js <url> <one|two|four|nogm> [desk|phone] [worlds|all] [--shots dir]` يلعب كل المهام بالماوس/اللمس، يفحص: لا توكن خام في الصفحة ولا في الكانفاس، لا اسم حقيقي داخل نص الصوت، ثبات التقدّم والعيلة بعد إعادة التحميل، صفر أخطاء كونسول. `wizard_shots.js` يمشي المعالج كوالد ويصوّر كل خطوة. `names_check.js` يتأكد أن الأسماء ظاهرة (بطاقات العوالم/المهام/عنوان المهمة/الحوار/اليوميات/الألبوم/المكالمة/ركن الأهل). `looktest.js` ورقة كل الأشكال. `leakcheck.js` فحص تسرّب مصطلحات المالك (نفس مصطلحات `tools/family/leakcheck.js`؛ الاستثناء الوحيد لقب «ننا» داخل `engine/family*.js` لأنه أحد خيارات الجدة).

# الإصدار الكامل لجوجل بلاي (طبقة الاشتراك + الأندرويد) — v2

**الأمر النهائي لإنتاج أصول الويب:**
```bash
node tools/play/build.js play_dist --force --title "مغامرات العيلة" --package-name com.yourname.familyadventures \
     [--privacy-url https://...] [--terms-url https://...] [--voice-dir <مجلد المقاطع+manifest.json>]
```
* `--package-name` الافتراضي = `appId` الموجود في `android/capacitor.config.ts` (فلا يختلف التطبيق عن الويب أبدًا). `--title` يظهر في شاشة البداية وفي نص الاشتراك (paywall/terms) — **لا** يظهر اسم أي طفل في نص الاشتراك.
* يكتب `window.MOODY_CONFIG = {edition:'play', packageName, privacyUrl, termsUrl, appTitle}` **قبل** `engine/config.js` (الإصدار ثابت: `?unlock=1` و`?edition=web` لا يعملان).
* نسخة الإصدار (بدون `--test-mock`) **لا تحتوي** مزوّد `mock` ولا `hubpay` (شفرة وتعليقات وواجهة كود التفعيل كلها محذوفة): `grep -riE "mock|hubpay|activation" play_dist/engine` = لا شيء. الاشتراك مجاني للمهمة الأولى في كل عالم، والباقي خلف البوابة الأبوية + Google Play Billing (مزودات `capacitor` / `digitalgoods`).
* لا يوجد `../` في `index.html` (حُذف `pwa-game.js` و`sw.js` و`manifest.json` و`<link rel=manifest>`)، ولا `paywall.js` ولا رابط للهب ولا مقاطع التشجيع من `../sonic`. `android/scripts/make_www.js` يمرّ بدون أخطاء (تحذير واحد مقبول: نص `https://play.google.com/billing` داخل `billing.js`).
* **المعالج هو أول شاشة** عند أول تشغيل (قبل العنوان وقبل الخريطة)؛ لا روابط خارجية ولا جمع بيانات فيه (كل شيء في `localStorage` على الجهاز).
* **للاختبار فقط:** `--test-mock` يُبقي المتجر التجريبي (`allowMock`, `billingProvider:'mock'`) ليمكن شراء اختباري. **لا تُسلِّم** ناتجه؛ الاختبارات تتحقق أن بناء الإصدار لا يحتويه.

**كيف يستدعيه `.github/workflows/android.yml`:** خطوة «Build the Play-edition web assets» تشغّل `node tools/play/build.js "$WEB_OUT" $WEB_ARGS` (الافتراضي `play_dist` وبدون وسائط)، ثم `make_www.js --src ../$WEB_OUT`. ما دام `appId` في `capacitor.config.ts` صحيحًا فلا يلزم أي وسيط؛ وإلا مرّر في `web_build_args` مثل: `--title "مغامرات العيلة" --package-name com.yourname.familyadventures --privacy-url https://...` (كل المفاتيح تُكتب في `MOODY_CONFIG`). لتضمين السرد: جهّز المجلد بـ `voice.py gen ... --provider azure` ثم `--voice-dir`.

## البنات فقط (ميزة جديدة: تعديل الصيغة وقت التشغيل)
`engine/family_flip.js` (+ `Moody.family.assign()`): لو اختار الأهل أقل من ولدين، **الثنائي الأساسي (moody/aboody) يلعبه أول طفلين** (الأولاد أولًا، ثم البنات بالسن)، والبنت في خانة ولد تتحول لبنت (شكل + صوت + صيغة النص). كل سطر **تقوله** تلك الشخصية (ويقول «أنا») أو **يتكلم عنها** بالتوكن `{m}`/`{a}` يمر على جدول المذكر→المؤنث (نفس جدول `tools/family/lib/gender.js`، جملة بجملة): `أنا جاهز`→`أنا جاهزة`، `{m} الطويل`→`{m} الطويلة`، `{a} يزحف`→`{a} تزحف`. مفتاح: «خلّي البنات الأبطال الأساسيين» في خطوة الأطفال (افتراضيًا شغّال؛ لو أُطفئ يرجع السلوك القديم). السرد: نفس التحويل على النص + فئة الصوت (girl_big/girl_small) + كلمات محايدة مؤنثة (الكبيرة/الصغيرة/يا بطلة) + «ملح» `g` في hash المقطع (لأن نفس النص بصوت بنت مقطع مختلف): كل ذلك في JS وPython (`check_neutral.js`: ٤٣٤ ألف مقارنة بلا فرق). `flip_test.js <outdir>` يكتب `flip-review.txt` بكل سطر تغيّر.
**حدود:** جدول منسّق لا ذكاء اصطناعي: أوامر اللاعب («اضغط») تبقى بالمذكر عمدًا؛ سطر قد يُقلب خطأ لو فيه «أنا» لكن الصفة عن غيرك (نادر)؛ كلمات مثل «ولدين» بلا توكن لا تتحول؛ ٣ بنات أو أكثر: الثالثة والرابعة في خانتي البنات الطبيعيتين (بلا تحويل). ولد + بنت: الأكبر سنًا يأخذ خانة moody.

## الاختبارات (v2)
`gate_test.js <url> <two|four|nogm|girls> [desk|phone] [shots]` (بناء `--test-mock`): المعالج أول شاشة وتُملأ بالواجهة، ثم `?unlock` معطّل، أول مهمة فقط في كل عالم، كل مهمة مقفولة تفتح البوابة الأبوية (لا المهمة)، شراء اختباري عبر الواجهة (إمساك ٣ ثوانٍ + مسألة + اشتراك شهري)، واستمرار الاشتراك والعيلة بعد إعادة التحميل. `e2e.js ... --wizard --premium` يلعب كل المهام بعد ذلك. `flip_test.js` مراجعة الصيغة.
